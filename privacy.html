Privacy Policy — Personal Life Log

Effective date: September 26, 2026

Personal Life Log is a private, personal-use application intended for use by its owner. It is not currently offered as a public service.

1. Data the application may access

With the user's explicit authorization, Personal Life Log may access categories of Oura data made available through the Oura API, including daily summaries, heart-rate data, workout data, SpO2 data, stress-related data, and heart-health data, only to the extent the user grants the applicable permissions.

The application may also process information entered by the user or obtained from other services the user separately authorizes, such as habits, tasks, journal entries, training records, nutrition records, body-composition measurements, calendar events, and photos.

2. Purpose of processing

Data is used only to provide personal functions requested by the user, including displaying personal health and activity information, tracking long-term changes, generating private summaries and reports, synchronizing the user's own devices, and performing personal statistical analysis where permitted by the relevant data provider's terms.

3. Data minimization

The application requests and processes only data reasonably necessary for enabled features. Optional integrations and permissions are not used unless the user enables them.

4. Storage and retention

Data is stored only as needed to provide the user's authorized personal functions and in accordance with the terms that apply to the relevant data source. Oura data obtained through the Oura API is retained only for the duration strictly necessary for authorized purposes and subject to the Oura API and MCP Agreement.

The application is designed to keep personal data separate from the public source-code repository. Authentication credentials, access tokens, refresh tokens, health records, journal content, and private photos are not intentionally published to GitHub.

5. Sharing and disclosure

Personal Life Log does not sell personal data, use it for advertising, or disclose it to unrelated third parties. Data may be transmitted to service providers only when necessary to provide a feature explicitly enabled by the user and only where such use is permitted by the applicable provider terms.

6. Artificial intelligence

Oura data obtained through the Oura API will not be provided as input to an AI model or AI platform where prohibited by the Oura API and MCP Agreement. Personal Life Log does not use personal health data to train, fine-tune, develop, or improve AI models.

7. Consent and revocation

Access to Oura data is based on the user's explicit OAuth authorization. The user may revoke authorization through Oura or disable the integration. After consent is revoked, the application will cease collection and processing of Oura data and will delete Oura user data when required by the applicable agreement or when the user requests deletion.

8. Security

Reasonable safeguards are used to protect personal data, including keeping secrets and authentication tokens out of the public repository, limiting requested permissions, and using secure storage mechanisms where available. No system can guarantee absolute security.

9. Medical disclaimer

Personal Life Log is a personal tracking and analysis tool and is not a medical device. It does not provide medical diagnosis, treatment, or emergency services. Health information and derived statistics should not be treated as a substitute for professional medical advice.

10. Third-party services

Third-party services, including Oura, are governed by their own terms and privacy policies. Personal Life Log is not affiliated with or endorsed by Oura unless expressly stated otherwise.

11. Changes to this policy

This policy may be updated when the application's data practices or integrations change. The effective date above will be updated when material changes are made.

12. Contact

Questions about this policy can be submitted to the repository owner through the public project repository: github.com/Bomber930/personal-life-log-legal.
